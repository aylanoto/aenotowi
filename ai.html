Claude responded: Your repository URL is the address of your repo on GitHub (not the live website).

Your repository URL is the address of your repo on GitHub (not the live website). It follows this pattern:

https://github.com/YOUR-GITHUB-USERNAME/YOUR-NETID

The lab’s example is https://github.com/mjdemari2/mjdemari2, where the username and the repository name happen to both be mjdemari2.

How to find yours:

  1. Sign in to GitHub and click your profile icon (top right) > Repositories.
  2. Click your repository (the one named after your NetID, in all lowercase).
  3. Copy the address from your browser’s address bar. That’s your repository URL.

Don’t confuse it with the live site URL, which is the second thing you submit:

WhatLooks like
Repository URLhttps://github.com/username/netid
Live site URLhttps://username.github.io/netid/

For the Blackboard submission, type all three:

  1. Your NetID
  2. Your live site URL
  3. Your repository URL

If you haven’t created the repository yet, that’s Part 2 of the lab. You’ll need it before Part 6 (uploading your files and turning on GitHub Pages).
